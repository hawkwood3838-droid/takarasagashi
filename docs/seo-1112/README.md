## 2. 検索されそうな言葉と、見出し・説明文への入れ方の案（まだ本文には入れていません）

WebSearch で調べた結果、日本語で「名前入り・家でする宝さがしのPDF」を売っているページはほとんど見つからず、出てくるのは英語の印刷用キットや、手作りのやり方の記事でした。**「手作りのかわりに、印刷するだけ」**という言い方が合いそうです。

| ねらう言葉 | どこに | 案（誇大にしない） |
|---|---|---|
| 宝探し 家 子ども 誕生日 | index のリード文 | 「お誕生日やクリスマスのプレゼントを、**家でできる宝さがし**にして渡しませんか。」（今の文に「家でできる」を足すだけ） |
| 宝探し 謎解き 暗号 | index の h2「遊び方」 | 「遊び方（家の中で、暗号をといて宝さがし）」 |
| 名前入り プレゼント 子ども PDF | index のしめの h2 | 「その子の名前で作ります」→「その子の名前入りで作る、PDFのプレゼント」 |
| 人生すごろく 手作り | すごろく の h2「どんな すごろく？」の下 | 「手作りしなくても、印刷するだけで遊べる人生すごろくです。」を1文足す |
| なりたい職業 すごろく | すごろく の h2「えらべる職業」 | 「えらべる職業（なりたい職業が すごろくに入ります）」 |
| アドベントカレンダー 手紙 | santa の h1 の下 | 小見出しに「名前入りの なぞときアドベントカレンダー」を出す（今は本文の最後にだけある） |
| サンタからの手紙 名前入り | santa のリード文 | 今の文で入っている。変えなくてよい |

※ description（検索結果に出る説明）には、上の言葉をすでに入れました（「家でできる宝さがし」「印刷するだけ」「なぞときアドベントカレンダー（印刷して使うPDF）」など）。
